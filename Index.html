▸ Advanced crating settings
These caps apply to net (content) weight only — the crate's own material weight (tare) is added on top and shown separately as gross weight, and can end up above this cap since it isn't restricted by it.
Item clearance = spare space added around each part on every side inside the packing grid — it's the allowance for wrap/foam/dunnage between neighboring parts and between the outer parts and the inner crate wall. It drives how far apart parts sit, which sets the internal crate size. Set to 0 for parts stacked edge-to-edge with no padding.
Walls are built from vertical + horizontal 0.75 in wood pieces layered together (1.5 in per side, 3 in added to each of L/B/H going internal → external). Min last-crate fill ratio: if the leftover quantity after filling full-size crates would fill less than this fraction of the template crate, the tool builds a separate, properly-sized smaller crate for that remainder instead of shipping a mostly-empty big one. Above this ratio, it keeps the same crate and calls out the dunnage space to block instead.
Pillar B = thickness across the gap direction (along crate length L) — governs pillar footprint and how much length the pillar layout needs. Pillar H = thickness added to crate height (2 pillars stacked: base skid + top resting rail).
Same gap target across the fleet so any crate can be loaded above another with pillars aligned for load transfer. Rule: if the crate's content-driven length already reaches the preferred gap, keep it as-is. Else if that length is already ≥ the "big-crate" reference, stretch it to get the full preferred gap. Else if the minimum-gap length still fits under that reference, stretch to the minimum gap. Otherwise the crate is small enough that no gap is forced — pillars just sit at the edge offset.
